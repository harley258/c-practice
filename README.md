# c-practice

> A2（C 语言，第 2–7 周）与 A3（C++，第 4–11 周）的练习仓库。
> **验收标准：A 阶段结束时 ≥30 个练习，且含环形缓冲区、状态机各一份。**

学法提醒：**每集视频必跟写**，只看不写等于没学。每周 5–6 个小练习提交到这里。

## 目录约定

```
c-practice/
├── README.md
├── c/            ← C 语言练习（01_basics/、02_pointer/ …）
└── cpp/          ← C++ 练习（A3 起用）
```

每个练习一个小目录，含源码 + 一行编译命令（或 `Makefile`）：
```bash
gcc 01_swap.c -o 01_swap -Wall -g && ./01_swap
```

## C 语言练习清单（按课程顺序推进，打勾即提交）

- [ ] 手动实现 `strlen` / `strcpy`

### 04 数组与字符串
- [ ] 冒泡 / 选择排序

### 05 结构体 / 联合体 / 枚举
- [ ] 学生结构体数组：录入 + 按分数排序
- [ ] 用 enum 写一个状态枚举

### 06 动态内存
- [ ] 动态数组的增（realloc 扩容）

### 07 位运算与位域（嵌入式方向重点）
